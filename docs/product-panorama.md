```text
PhotoFlex
│
├── Projects Overview
│   ├── 进行中的项目
│   ├── 最近活动
│   ├── 当前阶段
│   └── 新建项目
│
├── Project Workspace
│   ├── Project Overview
│   ├── Research
│   ├── Field Work
│   ├── Reflection
│   ├── Editing
│   ├── Output
│   ├── Timeline
│   ├── Decision Log
│   ├── Research Library View
│   └── AI Reflection Assistant
│
├── Settings
│   ├── JSON Export
│   ├── Clear Local Data
│   └── AI Configuration

└── Future
    ├── Feedback Link

    ├── Public Archive
```

## 核心数据关系

```text
Project
  ├── Stage Records
  ├── Decisions
  ├── Timeline Events
  ├── References
  ├── Project Summary
  └── AI Conversations
```

## 项目阶段

```text
Research → Field Work → Reflection → Editing → Output
    ↑                         │
    └─────────────────────────┘
```

阶段是可切换的工作区，不是强制线性流程。用户可以回到任意阶段，也可以从 Reflection 回到 Research。

## 桌面端工作区

```text
┌──────────────┬──────────────────────────┬─────────────────────┐
│ Project Nav  │ Main Workspace           │ AI Assistant        │
│              │                          │                     │
│ Overview     │ 当前阶段内容              │ 项目上下文摘要       │
│ Research     │ 阶段提示                 │ 对话记录             │
│ Field Work   │ 引导字段                 │ 输入框               │
│ Reflection   │ 自由正文                 │                     │
│ Editing      │ 参考链接/图片占位         │                     │
│ Output       │ 保存与更新时间             │                     │
│ Timeline     │                          │                     │
│ Decisions    │                          │                     │
└──────────────┴──────────────────────────┴─────────────────────┘
```
