# PhotoFlex 开发流程与测试方案

## 功能开发流程

每个功能遵循：

1. 明确用户行为
2. 定义领域规则
3. 编写失败测试
4. 实现最小代码
5. 运行测试
6. 重构模块边界
7. 集成 UI
8. 手动验证真实流程
9. 小步提交

## 测试层级

### Domain Tests

- 项目创建
- 阶段切换
- 阶段记录创建和更新
- 决策状态变化
- Timeline 事件生成
- 示例项目识别
- JSON Export 完整性
- Clear Data 行为

### Repository Tests

- 保存后可读取
- 刷新后数据仍存在
- 多项目互不覆盖
- 删除项目行为正确
- 导出数据可重新解析
- 损坏数据不会导致应用崩溃

### AI Tests

- 完整项目上下文是否被传入
- 当前项目 ID 是否正确
- Summary 是否只在主动触发时生成
- Provider 错误是否显示清晰提示
- AI 不会自动写入用户记录
- API key 不出现在客户端 bundle

### UI / Integration Tests

至少覆盖：

1. 创建项目
2. 打开项目工作区
3. 切换五个阶段
4. 保存阶段记录
5. 创建 Decision Log
6. 查看 Timeline
7. 查看 Research Library
8. 生成 AI Summary
9. 导出 JSON
10. 清除本地数据
11. 删除示例项目
12. 刷新后恢复数据

## 手动验收流程

```text
创建项目
→ 写下原始意图
→ 添加研究问题
→ 添加参考资料
→ 记录现场拍摄
→ 记录偏离计划的地方
→ 写 Reflection
→ 创建创作决定
→ 回看 Timeline
→ 生成 AI Summary
→ 导出 JSON
```

## 第一轮成功信号

- 是否愿意连续数天重复打开
- 是否愿意记录真实项目
- 是否能快速找到过去的创作决定
- 是否能解释项目如何发生变化
- AI 提问是否带来新的反思
- 是否认为结构化记录比普通聊天更有价值

## 当前明确排除项

- Feedback Link
- 云端同步
- 账号系统
- 图片上传
- 社区和公开 Archive
- 多人协作
