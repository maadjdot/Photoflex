# Layout L2 验证记录

日期：2026-09-24
工作分支：`Layout-Develop`
范围：正式入口、创建、页面工作区和页面顺序。图像框编辑、文字编辑、阅读与 PDF 分别属于 L3–L5。

## 已交付

- Sequence 网格中的 Layout 入口会先等待 Sequence 保存；已有 Layout 直接打开，首次进入提供预设/自定义尺寸、方向及 Sequence/空白初始化。
- Sequence 初始化按 `readingUnits` 展开为物理页；spread 前在必要时插入真实空白页，创建面板显示插入数量。文字仅导入纯文本。
- 正式 Layout 路由验证项目、Sequence 和 Layout 的关联；缺失或链接不匹配时提供返回 Sequence 的错误页。
- 工作区包含顶栏、页面栏、纸张、页面属性和当前 Sequence 照片条。页面可以新增、复制、删除、前移、后移、撤销和重做；单页/对页查看不改变文档顺序，第一页位于对页右侧。
- 页面操作通过项目写入协调器自动保存；返回、浏览器路由变化和退出账号经过保存屏障。顶栏分别显示本地保存与云端状态，保存失败保留草稿并提供重试。
