# Layout L3 验证记录

日期：2026-09-24
工作分支：`Layout-Develop`
范围：Sequence 照片条、图像框、裁切、模板、保存与恢复。文字编辑、阅读和 PDF 属于 L4–L5。

## 已交付

- 照片条按当前 Sequence 的 photo item 顺序展示，重复照片保留各自条目。缩略图无底色并完整显示照片原比例；支持横向浏览、点击插入或替换、拖到空白页建框及拖到图像框替换；显示 Used/Missing，并可刷新照片状态。
- 图像框支持画框、添加空框、移动、八个方向的缩放手柄、毫米数值编辑、复制、删除和层级调整。移动或缩放时对齐页面边缘、中线、边距与同页对象，并显示蓝色对齐线；松手后对齐线消失。新照片默认以 Fit 完整显示，不给照片加灰色底色。指针移动只预览，松手形成一次文档命令；Escape 可取消未完成手势。
- 每个框可选择 Fit/Fill。双击照片进入直接裁切：在照片上拖动调整位置、滚轮以指针位置为中心缩放，照片上的 Done/Enter 一次提交，Cancel/Escape 放弃；右键拖动照片可像 Frame 一样快速调整并在松手时提交。编辑与预览使用共享的图像定位规则。
- 页面列表支持拖动调整页序，保持当前页选中；仍可通过按钮前移和后移。
- 工作区、右侧设置栏与 Frame 采用相同的白色表面、分区标题、模板图标、分段按钮和输入控件，并参考所给 Figma Make 的 Layout 编辑画面。右侧设置栏为贴边、直角、占满右侧的面板。
- 五种模板以共享几何规则生成普通图像框。可调边距、间距及双联/三联方向，可从照片条选择照片按序填入。替换当前页图像框前确认，文字框保留，整个模板应用是一次撤销操作。
- 页面只保存照片 ID、框尺寸和裁切参数，不写入原片或临时 URL。可见页图像通过 PhotoSource 预览 lease 加载，离开页面时释放；照片不可用时保留框和引用。
