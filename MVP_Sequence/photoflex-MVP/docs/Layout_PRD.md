## 1. 产品目标与范围

让摄影师从已经整理好的 Sequence 进入 Layout，将照片放入可自由调整的图像框，加入标题和说明，完成摄影集或作品集的页面排版、阅读和 PDF 输出。

首版完整覆盖七项能力：页面规格、图像框、图片缩放裁切、文字、五种模板、阅读、PDF。以摄影集排版为核心，采用 InDesign 的“页面—框—框内内容”操作概念。

首版不包含：印刷厂交付标准 PDF/X、CMYK/ICC 管理、专色、出血与裁切标记、拼版、母版、连贯文本流、任意矢量绘图、多人实时协作、插件市场。它们会显著改变产品和技术成本，应另立需求。

### 1.1 默认产品决策

以下是为了使 agent 能直接实施而确定的建议默认值，不代表用户已确认所有细节：

| 问题 | 首版决策 | 原因 |
|---|---|---|
| 一个 Sequence 有几个 Layout | 一个；再次进入恢复原文档 | 减少入口和文档管理复杂度，数据仍使用独立 LayoutId |
| 编辑器范围 | 桌面浏览器，优先现有 Chrome / Edge | 与当前项目一致 |
| 默认规格 | A4 竖版、单页物理尺寸、Facing Pages、首张为右页 | 适合摄影集，单双页切换不影响实际页数 |
| 默认创建方式 | 按 Sequence 的阅读顺序生成，可选从空白开始 | 首次进入即有内容；自由排版仍可完全调整 |
| 序列变化 | 照片库更新；已排页面不自动重排 | 防止前序调整破坏已完成排版 |
| 首版文字 | 文本框整体样式、简体中文和拉丁文字 | 避免富文本、跨框流排带来的复杂度 |
| PDF 定位 | 固定物理尺寸的 RGB 阅读/作品集 PDF | 不默认承诺专业印刷交付 |
| 图片清晰度 | 阅读稿及高清两档；高清按需读取原片 | 保留现有预览策略，并让输出足够清晰 |

## 2. 用户主流程与导航

1. 用户在 Table 打开某个 Sequence 弹层，点击 `Layout`。
2. 等待当前序列编辑保存完成；失败时保留序列界面、显示现有恢复入口。
3. 已有 Layout：直接恢复；没有 Layout：显示创建面板，设置尺寸、方向、单双页、页边距及初始化方式。
4. 创建成功后进入独立 Layout 工作区，默认选中第一张页面。
5. 从下方照片条拖入页面或空框，拖动画框、调整尺寸、双击进入裁切；可加入文字或使用模板。
6. 自动保存；点击 Read 隐藏编辑工具，检查整本书；退出后回到之前页面和选中状态。
7. 点击 Export PDF，选择范围、按单页/跨页输出、质量，检查问题，导出。
8. 返回 Sequence 时恢复对应序列；返回 Table 时恢复原桌面视角。

生产入口必须接在当前 `SequenceOverlay` 流程。仓库里的旧 `SequencePage` 与 `/prototype/layout` 不代表当前正式入口。

建议路由：`#/projects/:projectId/sequences/:sequenceId/layout/:layoutId`。新建动作通过按钮触发，刷新路由不得重复新建。URL 中的项目、序列、Layout 必须相互匹配；缺失/已删除对象显示可返回的错误页。

## 3. 工作区结构

| 区域 | 内容及行为 |
|---|---|
| 顶栏 | 返回 Sequence、文档名称、保存状态、撤销/重做、Read、Export PDF |
| 工具栏 | 选择、图像框、文字、裁切；尺寸、单/双页显示、模板；适应页面、缩放 |
| 左栏 | 页面缩略图、页码、当前页；新建、复制、删除、拖动排序；总览切换 |
| 中央 | 白色页面和灰色工作区；当前单页或对页；缩放和平移；页面间视觉间隔不属于纸张 |
| 右栏 | 随选择变化：文档、页面、图像框、框内照片、文字；数值输入和层级调整 |
| 下栏 | 当前 Sequence 的照片，按出现顺序排列，标记使用次数、未使用、不可用 |

建议布局：左栏 176–208px，右栏 256–288px，底栏 112–144px。1440px 可同时展开；1280px 可以收窄和折叠；1024px 默认折叠左栏、右栏用抽屉，核心按钮可用。具体宽度按项目设计 token 调整，不作为固定像素验收。

没有选择对象时右栏显示页面设置；选择图像框显示位置、尺寸、Fit/Fill、替换、清空、图层顺序；进入裁切模式显示照片缩放和平移；选择文本显示文字样式及溢出提示。多选时只显示共同可修改的属性。

## 4. 详细功能需求

### L01：文档和页面规格

支持 A4（210×297mm）、A5（148×210mm）、Letter（215.9×279.4mm）、Square（210×210mm）、Panoramic（297×148mm），以及自定义宽高。非标准尺寸为产品预设。自定义每边 50–600mm；横/竖切换交换宽高。

页面尺寸始终表示一张物理页面。双页显示把两个页面并排，不能将 A4 双页错误保存为两张 A3，也不能因为窗口宽度变化而改变 PDF 尺寸。

页边距四边默认 12mm，间距默认 6mm，作为模板生成和吸附参考。用户仍可把框自由放在边距外。文档全册统一尺寸，首版不做混合纸张。

修改已有文档尺寸时预览两种策略：默认“保留对象物理尺寸和位置”；可选“等比缩放内容并居中”。后一策略用新旧页面的较小比例因子统一缩放位置、框、字号及行距，保持图像比例；页面背景改为新尺寸。若内容超出纸面，提示并允许撤销，不能静默重排或删除。

尺寸输入只接受有限正数，单位换算不得随画布缩放改变；错误输入保持上次有效值。

### L02：单页、对页及页管理

- `Single`：一次显示一张页面。
- `Facing Pages`：第一页单独显示在右侧，随后 2–3、4–5……并排；末尾无配对页显示灰色占位，不计入文档或 PDF。
- 切换显示模式不增删页面、不修改对象坐标，也不产生内容撤销步骤。
- 可新增空白页、复制页、删除页、排序。至少保留一页；复制生成新页面和对象 ID，照片引用保留。
- 拖动页缩略图结束时一次提交；支持菜单“前移/后移”替代拖动。
- 页码来自当前页面顺序，1 起算；页面 ID 永久稳定。
- 重排后对页重新按奇偶组合，页面内内容不动。UI 显示新的组合。
- 首版框归属一张页面，不支持一个对象跨装订线；满版指单张页面满版。

**由序列初始化**：按 `readingUnits` 展开，single → 一页，blank → 真正空白页，spread → 连续两页，text → 一页文本框；重复照片保留各次出现。单页显示模式下，spread 仍转换为两张物理页面。

若选择 Facing Pages 并保留序列 spread，则 spread 第一张应落在偶数页：必要时在其前插入真实空白页，并在创建预览说明新增的空白页数。例：从 spread 开始的序列生成空白第 1 页 + 第 2–3 页。首版导入文字保留纯文本与合理字号，旧 `html` 不直接注入新编辑器；显示一次“文字格式已简化”提示。从空白创建时只生成一页，不消耗任何照片。

### L03：图像 Frame

图像框和框内照片是不同的编辑对象。框可以为空；一个框包含一张照片；同一张照片可以用于多个框，各自拥有独立裁切参数。

支持：画矩形空框；单选、Shift 多选；拖动；八个控制点缩放；数值设置 X/Y/W/H；复制、删除；前移、后移、置顶、置底；锁定/解锁。首版无任意形状与旋转。

X/Y 相对所属页面左上角；最小框尺寸 1mm，不能反向拖成负数。Shift 缩放锁定比例。默认吸附页面边缘、页边距、中心线和其他框边缘，屏幕距离 6px 内吸附，按 Alt 暂时关闭。数值输入可精确绕过吸附。

框可部分超出纸面，输出裁切到页面；至少保留 1mm 与页面相交，防止对象完全丢失。文字工具遵循相同边界。支持将选中对象移至左/右邻页的菜单操作，以确定的新页坐标保存；首版不做跨页拖动的复杂命中。

拖一张照片到空白页面时创建框，默认落点为中心、宽度为内容区一半，按照片比例确定高度并限制在内容区；到已有框时替换照片，保留框位置、尺寸和层级，裁切重置为 Fill 居中。照片元数据尚未就绪时保持加载反馈，失败不创建半成品。

多选提供移动、复制、删除及层级操作；数值宽高调整和控制点缩放首版仅支持单对象，避免不同对象比例被意外破坏。

### L04：照片缩放、平移和非破坏裁切

- 单击选框；双击照片或点击 Crop 进入框内编辑。Esc 取消本次裁切，Enter 或点击完成提交。
- 裁切模式下框外图像可用暗色遮罩展示；框本身不随照片平移。
- `Fit` 完整显示照片，允许留白；`Fill` 填满框，必要时隐藏部分照片。两者均保持比例。
- 缩放滑块 100%–800%，100% 相对所选 Fit/Fill 的基准缩放；提供重置和居中。
- Fill 平移受限，不能露出空白。Fit 允许留白，但小于框的轴保持居中；大于框的轴可平移。
- 调整框尺寸时保留已选模式、缩放倍数和视觉焦点，再重新约束有效裁切范围。
- 画布缩放只影响观看比例；照片缩放影响成品构图。两者独立。
- 一个拖动/滑块手势记一次撤销，指针每次移动不写数据库。
- 裁切和缩放只保存参数，绝不修改原片。

### L05：文字工具

点击或拖出文本框，双击进入文字输入。支持多行纯文本、换行、字体、字号、颜色、粗体（有对应字重时）、行距、左/中/右对齐。首版整体文本框统一样式；段落的显式换行保留。

首版字体范围：一套中英文字体，以及一套通过 PDF 验证的西文衬线字体；最终字体文件在阶段 0 锁定。字体缺失时不能静默换成导致版面变化的系统字体。现有网站 UI 字体与排版字体可以不同。

默认 12pt、行距 1.4；字号范围 6–144pt，行距范围 0.8–3。文本框缩放默认只改变排版宽高，不缩放字号。可在属性栏修改内边距，默认 0。

文字溢出时显示清晰红色标记，属性栏说明“部分文字超出文本框”。导出前必须修复，不能默默截掉文字。空文本框不构成导出错误，也不打印边框。

中文输入法组合输入期间不提交编辑命令、不响应撤销等文档快捷键；组合输入结束后再保存。粘贴按纯文本处理。编辑文字时 Backspace/Delete 操作文字，不能删除页面或图像框。

暂不支持局部富文本、链接、列表、自动连字配置、竖排、RTL、彩色 emoji 和跨框流排。遇到不支持的字符/缺字，显示具体字符和位置，让用户修改，不能导出方块字。

### L06：五种可调整模板

模板是一次性生成框的规则。应用后产生普通图像框，用户可任意移动、缩放、替换、增删；后续调整不受模板约束，也不因模板升级而变化。

| 模板 | 默认构成 | 首版可选方向 |
|---|---|---|
| Single | 页边距内一个大图像框，照片默认 Fit | 无 |
| Diptych | 两个等大图像框，间距 g | 左右或上下 |
| Triptych | 三个等大图像框 | 横排或竖排 |
| Quad Grid | 2×2 四框 | 无 |
| Full Page | 覆盖单张纸面的图像框，照片默认 Fill | 无 |

默认应用到当前选中的单页；对页中必须明确选中左页或右页。菜单可选择“应用到当前两页”，分别生成两个页面的模板，用一个撤销事务完成，不能误解成跨页框。

填图规则：优先使用照片条中选中的照片，按序列顺序填入；没有选择时，先复用当前页现有图像框中的照片（按层级顺序），再从序列未使用照片中补齐。多余选中照片继续保留选中；照片不足留空框。

应用模板替换目标页全部图像框，保留文字框。非空目标显示小型预览和“将替换 N 个图像框”提示，确认后作为一次撤销；被移除的照片仍在图库。现有裁切在新模板中重置，预览必须体现。TemplateId / version 仅保存为来源标记，不维护动态依赖。

模板参数为页边距和框间距。参数改变仅影响本次预览或新应用；不会自动改动之前手工调整过的页面。首版不包含用户保存模板、模板商店及整本书自动优化排版。

### L07：Sequence 照片库

照片条只显示当前 Sequence 中的 photo items，不含 blank/text，按出现顺序显示。重复 PhotoId 仍保留各个 SequenceItemId 对应卡片；使用次数按 PhotoId 统计，所以重复卡片显示相同的使用计数。

支持横向滚动、选择照片、拖入框、单击后“插入当前页”、只看未使用照片。预览沿用现有 PhotoSource/PreviewLease，不复制原片，也不把 Blob/URL 写入 Layout 文档。

| 外部变化 | Layout 行为 |
|---|---|
| Sequence 重排 | 照片条跟随；页面和裁切保持 |
| Sequence 新增照片 | 出现在照片条；不自动增加页面 |
| 从 Sequence 移除照片 | 照片条移除该次出现；已有框保留 PhotoId，若不再属于序列则标记 |
| 原片离线/授权丢失 | 已有框保留，显示占位和重新连接入口；文字、位置仍可编辑 |
| 删除来源目录引用 | 不清除 Layout 框，导出报告不可用照片 |
| Sequence 重命名 | 面包屑刷新；Layout 自己的名称不自动覆盖 |
| 删除 Sequence | 现有删除确认加入关联 Layout 数量；确认后在同一持久化事务删除序列、版本和 Layout |
| 删除 Project | 按现有删除流程清除所有相关 Layout |

不提供自动“重新根据 Sequence 排整本书”。如后续加入，必须是明确的重建命令，不能隐式运行。

### L08：阅读模式

使用与编辑器相同的页面内容与裁切结果，隐藏边框、手柄、辅助线、工具栏及缺图以外的编辑提示。保留返回、页码、上一页/下一页、单页/对页、适应窗口；可进入浏览器全屏，拒绝全屏时仍能阅读。

左右键翻页，Home/End 到首末页，Esc 退出。缺图保留占位提示。阅读模式不接受编辑快捷键，不产生文档修改；退出回到进入前的页面、缩放和选择。

当前页和邻近页按需加载 2048px 预览；不要同时加载整本书的高清图。

### L09：PDF 导出

导出 Layout 当前已提交的编辑状态；点击时先结束文字输入/手势，固定一份文档快照，再导出。导出过程中继续编辑不会改变本次结果。若本地保存失败，说明仍可导出当前内存草稿；导出成功不能把保存状态改成成功。

选项：

- 范围：全部或物理页码范围，允许 `1-5,8`，展开后按原文档顺序输出。
- 输出方式：默认每张物理页一张 PDF；可选对页合并（仅全部页面，避免任意范围造成含义不明）。
- 对页合并时：首页独立，2–3 合并，4–5 合并；无配对末页独立，不输出灰色占位、不额外补白。
- 阅读稿：使用现有 2048px 预览；高清：根据可见照片尺寸与目标 300ppi 生成图片数据，不放大低分辨率原片。
- 名称：默认 Layout 名称；处理文件名非法字符，支持中文。

物理尺寸、框位置、裁切、层级、字体与阅读模式保持一致。文字为可选取的 PDF 文本、字体嵌入；照片为嵌入图片。不得用整页截图替代正式导出。

导出预检：缺图、空图像框、字体缺失/缺字、文字溢出阻止导出，并定位具体页/对象；低清晰度只提示，用户可以继续。空白页和空文本框合法。没有图像/文字对象的页面输出为真正白页。

进度至少包含准备资源/已完成页数/生成文件，支持取消和失败重试。同一界面同时一个任务。离开 Layout 或切换项目取消任务并释放资源。导出完成前不触发下载；失败不下载部分文件。

首版无 CMYK、出血、印刷拼版或 PDF/X 声明。Full Page 可铺到纸边，但不等于带出血的专业印刷文件。跨页输出用于阅读审阅，不是印刷拼版。

### L10：撤销、保存与恢复

所有内容动作可撤销/重做：页面增删排序、图像框变化、裁切、替换图、文本和样式、模板应用、纸张尺寸变化。选择、面板折叠、画布缩放、阅读翻页不加入内容历史。

自动保存按“已完成的用户动作”触发，可合并连续输入。文案区分本地保存与云端同步；本地成功不能冒充云端完成。保存失败保留内存草稿，并提供重试和恢复备份。

浏览器返回、返回序列、切换项目和账号退出，都必须纳入现有保存屏障。尚未提交的文字、待处理的保存计时器与正在进行的手势有明确处理，不依赖卸载清理函数完成异步保存。

刷新后恢复内容、页序、字体、裁切及上次页面；撤销历史仅本次会话有效。刷新前已显示“已保存”的内容必须可恢复。

## 5. 性能、体验与容量

首版主要验收样本：50 页日常文档、200 页大文档、500 个序列 photo items；重页面样本 50 个对象。容量不是现有实测保证，开发阶段必须测量。超过已验证范围提示较大文档可能变慢，不通过静默截断输入来达标。

只有当前单页/对页挂载编辑交互；缩略图列表和照片条虚拟化。首屏、Table、Sequence 不提前加载 Layout 编辑器、排版字体和 PDF 引擎。翻页或离开释放预览 lease。

主要拖动目标为常见桌面设备接近 60fps；回归判据见执行计划。首次进入允许明确加载状态，字体加载期间不能以错误字体保存排版结果。

基础可访问性：按钮有名称和键盘焦点；拖动有数值/菜单替代；缩略图和照片条可键盘选择；工具状态不只靠颜色表示。快捷键只在 Layout 活跃且焦点合适时生效。沿用中英本地化。

## 7. 后续扩展顺序

首版稳定后再评估：多 Layout 版本、保存自定义模板、跨页图像、文字段落样式、自动页码；真正出现印刷交付需求后再评估出血、色彩管理和独立印刷导出后端。首版文档模型和模块接口应允许增加类型，不预先实现这些能力。
