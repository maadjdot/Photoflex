# Layout 产品需求文档

日期：2026-09-24
状态：首版开发基线；L0–L3 已实施，L4–L5 待实施
开发分支：`Layout-Develop`；起点：`develop` 的 `5325e09`

配套文档：[技术方案](./Layout_Technical_Assessment.md) · [实施计划](./Layout_Implementation_Plan.md)。本文定义产品行为；技术方案定义模块接口与数据流；实施计划定义交付顺序和验收门槛。文档中的默认值是实施建议，不代替用户后续明确决策。

## 1. 目标与版本范围

摄影师从已有 Sequence 进入 Layout，使用该序列的照片制作摄影集或作品集，完成页面排版、阅读和固定尺寸 PDF 输出。Layout 服务于“选片与排序完成后的编排”，不成为第二套照片库或通用出版软件。

**首版必须形成完整闭环**：选页面尺寸与单双页查看、自由矩形图像框、非破坏缩放裁切、纯文本框、五种可调整模板、阅读模式、PDF 导出。左栏为页面总览，右栏为当前选择的属性工具，下栏为当前 Sequence 的照片。

首版保持轻量：一次只编辑一张物理页，或在对页视图中编辑其中一张；一个图像框放一张照片；文档全册同一物理尺寸；每个 Sequence 最多一个 Layout。Frame 属于 Table，Layout 是独立文档，二者共享几何和模板规则，不共享编辑状态。

| 首版交付 | 后续候选 |
|---|---|
| 常用纸张尺寸、自定义尺寸、单页/对页查看、页面增删与排序 | 已有文档改尺寸时自动缩放或重排内容 |
| 单对象矩形框、照片替换、Fit/Fill、焦点和缩放裁切 | 多选变换、锁定、跨页移动、复杂吸附 |
| 整框统一样式的纯文本、已验证的中英字体 | 局部富文本、多字体、跨框流排 |
| 五种模板，应用后变成普通可编辑框 | 自动选片填图、批量套用、用户模板 |
| 阅读模式；逐张物理页、固定尺寸的 PDF | 对页合并 PDF、页码范围、输出质量档位 |

不在首版承诺印刷厂交付格式、CMYK/ICC、出血与裁切标记、拼版、跨装订线对象、任意矢量图形、多人协作或网页托管。互动网页作品集是下一阶段的优先候选，见第 6 节。

## 2. 默认产品决策与入口

| 事项 | 首版默认 |
|---|---|
| 运行环境 | 当前桌面浏览器流程，优先 Chrome / Edge |
| 页面 | A4 竖版；一页始终指一张物理纸张；初始对页查看，第一页在右侧 |
| 创建 | 默认从 Sequence `readingUnits` 初始化；可以选择仅创建一张空白页 |
| 序列变化 | 更新下方照片条；已排页面和裁切不自动改动 |
| PDF | RGB 阅读/作品集 PDF，每张物理页一张 PDF 页，固定尺寸 |

入口接在当前 `SequenceOverlay`。点击 Layout 时先完成 Sequence 的待保存编辑；保存失败则留在原界面并提供现有恢复方式。已有 Layout 直接打开；首次进入显示尺寸、方向和初始化方式。创建动作只发生一次，刷新不得生成副本。返回 Sequence、Table、切换项目或退出账号时，必须处理尚未提交的文字、手势和保存任务。

建议路由 `#/projects/:projectId/sequences/:sequenceId/layout/:layoutId`；路由中的项目、序列与 Layout 必须匹配。缺失或已删除对象给出可返回的错误页。旧 `SequencePage` 与 `/prototype/layout` 不是正式入口，原型可作为界面参考，不能当作已实现能力。

## 3. 工作区与基本交互

| 区域 | 首版职责 |
|---|---|
| 顶栏 | 返回、文档名、真实保存状态、撤销/重做、阅读、导出 PDF |
| 左栏 | 页面缩略图、当前页、增删、复制、前移/后移；拖动排序可在其稳定后加入 |
| 中央 | 物理页面；单页/对页查看、适应页面、画布缩放与平移 |
| 右栏 | 页面规格，或选中框/照片/文字的位置、尺寸、样式与裁切设置 |
| 下栏 | 当前 Sequence 的照片，按出现顺序；拖入页面或选中框 |

无选择时右栏显示页面设置；选中图像框时显示 X/Y/W/H、Fit/Fill、照片替换、清空与图层顺序；进入裁切模式后显示照片焦点与缩放；选中文字框时显示文本样式与溢出提示。1280px 宽度下核心操作必须可达，窄屏可折叠侧栏。所有拖动操作均提供按钮、菜单或数值输入替代。

旧版 PRD 记录的 [Figma Make 原型](https://www.figma.com/make/iItk2N7ZreVggkLvPdHOvv/Create-Sign-In-Sign-Up-Page)仅供工作区结构参考；其中的按钮、模板名称和展示内容不代表当前代码已实现或本版需求。

## 4. 功能要求

### L01 页面尺寸与页面顺序

提供 A4、A5、Letter、210×210mm 方形、297×148mm 全景预设及 50–600mm 的自定义宽高；横竖方向通过交换宽高得到。页面和对象坐标以物理尺寸保存，窗口与画布缩放不改变纸张尺寸。首版页面尺寸在创建时确定；已排版文档的尺寸转换单独设计，不允许静默移动、缩放或裁掉内容。

支持新建空白页、复制页、删除页、前移/后移；至少保留一页。页面 ID 不因排序改变，页码由当前顺序计算。`Single` 每次显示一页；`Facing Pages` 首页单独在右，随后 2–3、4–5 成对显示；末页无配对时的灰色占位不是文档页，也不进入 PDF。切换显示方式不改文档内容。

从 Sequence 初始化时，按 `readingUnits` 展开：single 对应一页，blank 对应真实空白页，spread 对应连续两页，text 对应纯文本页；重复照片保留重复位置。为保证已有 spread 对应对页，必要时在其前插入真实空白页，并在创建预览中说明数量。旧 `html` 不注入编辑器，导入文字仅保留纯文本并提示格式简化。从空白创建只生成一页。

### L02 图像框与照片裁切

可以画空矩形框，也可以把照片拖到空白页自动建框。框归属一张页面，保存页面内的 X/Y/W/H；照片由 `PhotoId` 引用，同一照片可用于多个框，裁切参数各自独立。支持单选、拖动、八点缩放、数值调整、复制、删除、前移/后移。最小尺寸 1mm；超出纸边的部分在阅读和 PDF 中按纸张裁切。首版不支持旋转、任意形状和跨页对象。

把照片拖到已有框时替换照片而保留框几何；裁切重置为 Fill 居中。双击照片或选择 Crop 进入框内编辑，Enter/完成提交，Esc 取消。`Fit` 保留整张照片、允许留白；`Fill` 填满框且不露出空白。缩放范围为相对 Fit/Fill 基准的 100%–800%，支持平移焦点、重置和居中。画布缩放与照片缩放彼此独立。一个完整手势提交一个可撤销动作；原片从不修改。

首版仅实现页面边缘与页边距的基础吸附；数值输入可精确设定位置。多选变换、跨页移动和对象间复杂吸附留待实际使用反馈。

### L03 文字

可以创建、移动、缩放文本框，输入多行纯文本和显式换行。首版提供一套经编辑器和 PDF 验证的中英字体，统一设置整框字号、颜色、行距及左/中/右对齐；有对应字体文件时可提供粗体。字号默认 12pt。缩放文本框只改变排版区域，不默改字号。

中文输入法组合输入期间不提交文档命令；粘贴按纯文本处理。文字溢出时在页面和右栏标识，并定位问题；缺字同样明确提示。缺字和溢出在导出前必须解决。正式 PDF 的中文必须在目标阅读器中通过显示、复制和搜索验证，不能以仅能渲染或内部字体映射通过代替验收。

### L04 模板

首版提供 Single、Diptych（左右/上下）、Triptych（横/竖）、Quad Grid、Full Page。尺寸、边距和间距沿用现有 Frame 的几何规则。模板只对明确选中的单页生效，生成普通图像框；生成后框可自由调整、增删和替换照片，模板参数变化不追溯修改旧页面。

Table Frame 独有的 Square Nine Grid 不加入 Layout 首版模板列表。

首版模板创建空框；若用户明确选中照片，可按选择顺序填入，照片不足则留空。应用到已有图像框的页面会替换该页图像框并重置其裁切；执行前说明替换数量，整个操作可一次撤销。文字框保留。首版不自动从未使用照片中补齐，不批量应用到两页或全册。

### L05 Sequence 照片条

只显示当前 Sequence 的 photo items，按出现顺序排列；重复 `PhotoId` 可出现多次。显示已使用与缺图状态，支持横向浏览、拖入和点击后插入当前页。使用现有 `PhotoSource` 及预览 lease；文档只存照片 ID，不保存 Blob 或临时 URL。

Sequence 增删或重排时，照片条更新，已排页面保持。照片从 Sequence 移除或来源离线时，Layout 框保留引用并提示异常，不静默清空；可继续编辑其他内容，导出前定位不可用照片。删除 Sequence 时必须连同关联 Layout 做一致性删除，删除确认显示关联文档；备份、复制、云同步和账号切换均不得遗漏或混淆 Layout。

### L06 阅读模式

使用编辑器同一页面几何、裁切和文字排版结果；隐藏框线、手柄与编辑工具。支持前后翻页、页码、单双页查看、适应窗口和退出后恢复编辑位置。缺图仍显示明确占位。阅读不产生内容历史；预览按当前页及邻近页加载，离开后释放资源。

### L07 PDF 导出

导出点击时先结束正在进行的文字输入和手势，固定本次文档快照；随后编辑不影响本次文件。首版导出全部页面，每张物理页对应一张同尺寸 PDF 页，按文档顺序输出；空白页保留。图像按相同框位置、层级、Fit/Fill 与裁切嵌入；文字作为 PDF 文本嵌入，不能将整页截图作为正式结果。

预检列出具体页和对象：缺图、空图像框、缺字、文字溢出阻止导出；低分辨率照片给出提示但允许继续。空白页和空文本框合法。导出显示进度，支持取消、失败重试且不下载部分文件；同一工作区一次只有一个导出任务。保存失败时可以明确告知“导出当前内存草稿”，导出成功不得伪装成已保存。

### L08 撤销、保存和恢复

页面变更、框、照片裁切、文字和模板应用可撤销/重做；选择、面板状态、画布缩放和阅读翻页不进入内容历史。自动保存按已完成的用户动作触发，连续文字输入可合并；失败时保留内存草稿，提供重试与项目恢复备份。刷新后，凡曾显示“本地已保存”的页面内容、页序、文字及裁切都必须恢复；撤销历史仅在当前会话保存。界面区分本地保存与云端同步状态。

## 5. 质量与验收

首版以真实的 50 页、500 个 Sequence photo items、不同图像方向及中英文文字进行主要性能验收；200 页与单页 50 对象作为扩展测量样本，结果记录后再决定产品承诺，不用静默截断达标。只让当前页面或对页进入完整编辑交互；照片条和缩略图按可见范围加载。Table、Sequence 首屏不提前加载 Layout 编辑器、字体和 PDF 引擎。

| 编号 | 必须验证的闭环 |
|---|---|
| A01 | Sequence → 首次创建/再次打开/刷新 → 返回；不重复创建、不丢已保存内容 |
| A02 | 单页与对页切换、页面排序、空白页及 PDF 页数和物理尺寸一致 |
| A03 | 画框、换图、Fit/Fill、焦点裁切、撤销与重做；原片无变化 |
| A04 | 五种模板生成后可任意调整，替换前说明影响且一次撤销恢复 |
| A05 | 中文输入法、换行、溢出和缺字提示；编辑、阅读与 PDF 排版对应 |
| A06 | PDF 空白页、照片裁切、中文显示、复制与搜索在目标阅读器通过 |
| A07 | 离线或缺失照片、保存失败、取消导出时保留草稿且没有部分下载 |
| A08 | 备份导入、项目复制、云同步、账号切换、序列和项目删除保持关联数据一致 |
| A09 | 1280/1440px 操作可达；50 页、500 照片样本中可见资源按需加载 |

## 6. 后续扩展

首版稳定后优先评估互动网页作品集：从同一 Layout 文档导出可离线阅读的 `index.html` 与素材包，提供翻页、章节导航、照片放大及手机阅读布局。它是独立的导出实现，不改变 PDF 的物理尺寸语义，也不包含网站托管。另可评估 Sequence 节奏检查，如重复用图、未使用照片、连续满版和空白页分布。多版本、自定义模板、高级 PDF 与专业印刷输出依照实际需求再确定。
