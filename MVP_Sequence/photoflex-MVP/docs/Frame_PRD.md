# PhotoFlex 画布 Frame 功能需求文档

日期：2026-09-20

状态：首版已在 `frame` 分支实现；本文保留完整验收目标，实际落地与待验证事项见 [实现记录](./Frame_Implementation.md)。除用户明确要求外，文中默认值均为建议基线。

配套：[技术架构](./Frame_Technical_Architecture.md)

## 1. 目标与已确认要求

在 PhotoFlex 的 Table 无限画布上增加可编辑的“小页面”，让摄影师直接试摆一张或多张照片，比较留白、照片比例和组合效果。一个画布可以并排放置多个 Frame，用来比较不同排版方案。

用户已明确：

- Frame 位于现有画布内，用于模拟照片在页面上的效果。
- 参考提供的 Figma 设计。
- **排版模板使用 Layout 的模式，不采用该 Figma 文件的模板集合。**

文档采用 [Layout 需求文档 L06](./Layout_PRD.md) 的五种模板：**Single、Diptych、Triptych、Quad Grid、Full Page**，并按本轮需求增加 Frame 专用的 **Square Nine Grid**。仓库旧 `LayoutPrototype.tsx` 中的“留白单图、左右对页、满版跨页、一主二辅”属于另一套原型；本方案不将两套合并。

## 2. 参考设计与产品定位

[Figma Make：Framing tool for photos](https://www.figma.com/make/jzOIBUNisy9AbuqFd0Bs1l/Framing-tool-for-photos)，核对版本为 Version 7。已通过浏览器查看运行预览、点击 Frame 按钮并检查弹出面板；Figma 工具返回了源码资源清单，但本次未读取源码正文。

| 已观察到的设计 | PhotoFlex 采用方式 |
|---|---|
| 左侧竖向工具栏有 Frame 按钮 | 接入现有 Table 工具栏，与 Memo、Grid 等同级 |
| 按钮右侧打开白色模板卡片面板 | 沿用锚定弹出面板，显示缩略图、名称和照片位数量 |
| 紧凑的图标模板选择与分组设定 | 使用 Layout 五种模式及 Frame 专用九宫格；右侧栏按 Frame / 图像框选择切换 |
| 点阵画布内有带轻阴影的白色小页面 | 页面成为真实 Table 对象，可保存、移动和复制 |
| 页面外有简洁的信息及 Use 按钮 | 创建采用点击模板一次完成；已有 Frame 的设定显示在右侧栏，并取代 Photo Sources |

移动、裁切、保存等生产行为是本方案提出的需求，不视为已在 Figma 验证。颜色、字体和控件状态复用 PhotoFlex 现有样式。

术语必须区分：

| 名称 | 含义 |
|---|---|
| 页面 Frame | Table 上的一张页面，包含页面规格和多个图像框；背景可选黑或白 |
| 图像框 / 照片位 | 页面内限定照片显示范围的矩形，一个图像框最多引用一张照片 |
| 照片 | 项目已有的原始素材，通过 PhotoId 引用 |
| Table 照片卡片 | 某张照片在画布上的一次摆放，与 Frame 中的照片引用相互独立 |
| Layout | 面向完整摄影集的页面排版工作区；Frame 共享其模板规则和几何计算 |

## 3. 首版范围

首版包含：创建、六种模板、页面尺寸与方向、边距与间距、单张及批量填图、替换与清空、自由增删图像框、调整图像框位置和大小、对齐虚线、Fit/Fill 与裁切、移动与等比显示缩放、命名、复制、删除、置顶、黑白背景、圆角、出血辅助线、撤销重做、保存恢复和缺图状态。

首版以**一张 Frame 对应一张页面**为单位。多个 Frame 可在画布自由比较，不产生书籍页码或阅读顺序。

暂不包含：对页/跨页、文字排版、Frame 嵌套、任意形状与旋转、自动分页、整本书排版、Frame 导出、Export DPI、Caption、转换为 Sequence 或 Layout。完整出版和输出继续由 Layout 需求定义；后续转换需要独立设计，当前不增加入口。

## 4. 默认设置

| 项目 | 建议默认值及规则 |
|---|---|
| 页面规格 | A4 竖版；支持 Layout 已定义的 A4、A5、Letter、Square、Panoramic 和自定义 |
| 物理尺寸 | A4 210×297mm；A5 148×210mm；Letter 215.9×279.4mm；Square 210×210mm；Panoramic 297×148mm |
| 自定义范围 | 每边 50–600mm，与 Layout 保持一致；横竖切换交换宽高 |
| 背景 | 默认白色，可切换黑色；暂不提供其他颜色 |
| 画布层级 | Table 照片默认显示在所有 Frame 页面之上；选中 Frame 不改变这一关系，主动点击 Frame 的 Front 才将它置于照片之上 |
| 页边距 / 框间距 | 四边各 12mm / 6mm；Full Page 忽略两者 |
| 初始显示 | 长边 420 个 Table 世界坐标单位，与画布缩放独立 |
| 创建位置 | 无照片选择时在可见画布中心附近；有选择时放在选区附近空位，必要时平移视口使新页面可见 |
| 命名 | Frame 01、Frame 02……，允许用户重命名，重名不影响对象身份 |
| 默认照片模式 | Single 为 Fit；Diptych、Triptych、Quad Grid 为 Fill；Full Page 为 Fill |
| 默认填充顺序 | 模板槽位按从左到右、从上到下；输入照片按 Table 现有空间阅读顺序 |

小页面在画布上显示多大，与实际页面的宽高是两个设置。拖动页面角点只改变整体显示大小；修改“页面尺寸”才改变排版空间。

## 5. 模板规则

模板命名和基本几何规则共享 Layout；模板缩略图也使用同一规则生成。

| 模板 | 图像框数量 | 初始布局 | 参数 |
|---|---:|---|---|
| Single / 单图 | 1 | 页边距内一个大框，完整显示照片 | 页边距 |
| Diptych / 双联 | 2 | 两个等大框 | 左右（默认）/上下、边距、间距 |
| Triptych / 三联 | 3 | 三个等大框 | 横排（默认）/竖排、边距、间距 |
| Quad Grid / 四宫格 | 4 | 2×2 等大框 | 边距、间距 |
| Full Page / 满版 | 1 | 覆盖整张页面 | 无边距与间距 |
| Square Nine Grid / 正方形九宫格 | 9 | 3×3 等大正方形照片框铺满正方形页面 | 固定零边距、零间距；选用时页面转为正方形 |

模板是**一次性生成规则**。创建后保存真实图像框坐标，允许用户移动或缩放现有图像框；不在每次打开文档时重新计算模板，不因模板规则更新而改动旧页面。

边距和间距是生成参数，合法数值一经修改立即重排模板框，手动新增的图像框保留。Full Page 的框初始覆盖整页，手动调整后标记“已调整”，不再强制满版。

## 6. 详细交互

### F01：创建 Frame

1. 点击 Table 左侧 Frame 按钮，在按钮旁打开两列模板面板；再次点击、Esc、点击外部关闭。
2. 每张模板卡片显示名称、几何缩略图与照片位数量（1/2/3/4/9）。选择模板后创建一个 Frame，关闭面板并选中新对象。
3. 无照片选择时创建空页面，空框用浅色虚线与“拖入照片”提示。
4. 已选照片时，按 Table 空间阅读顺序填入；照片不足保留空框。
5. 选中照片多于模板容量时，卡片提示“已选 N 张，此模板可放 M 张”，暂不创建；用户可减少选择，或明确选择“仅使用前 M 张”。超过当前模板容量不会自动创建多个页面。
6. 新页面引用照片，原 Table 卡片保留位置、分组和关联关系。

主工具栏 Frame 按钮始终表示“新建”。修改已有页面的模板通过该页面工具条中的“更换模板”操作，避免同一个按钮随选择状态产生不同结果。

### F02：填图、替换与顺序

- 拖一张 Table 照片到空框：加入引用；拖到有照片的框：显示替换预览，松开替换，重置为该框默认 Fit/Fill、100%、居中。
- 普通点击照片仍选中 Table 卡片；拖动过程中命中 Frame 才高亮接收区域。
- 多张照片拖到页面空白区域：按输入空间顺序填入空框；有照片的框保持不变。空位不足时整批不提交，提示剩余空位数；不部分写入。
- 多张照片拖到单个已有框：不执行批量替换，提示“请拖到页面空白处或只选一张照片”。
- 拖放失败或 Esc 取消：页面与原卡片均恢复手势开始状态。成功填图后，原卡片也回到原位置。
- 选中照片时不显示“Place in Frame”菜单；通过拖放将照片加入 Frame。
- 页内提供“前一位 / 后一位”换位动作，交换照片及其裁切参数，随后按目标图像框重新约束焦点；图像框本身保持。
- 清空当前图像框只解除照片引用，保留空框。相同 PhotoId 可以用于多个图像框，各自独立裁切。

首版填图来源是当前 Table 的照片选择；不在 Frame 内新增独立上传器。新增照片继续使用项目现有素材导入流程。

### F03：选择与操作层级

| 用户操作 | 结果 |
|---|---|
| 单击未选中 Frame 的任意页面区域 | 选中整个 Frame，清除其他类型对象的选中状态 |
| 拖页面名称、边缘或空白区域 | 移动整个 Frame，所有页内内容随行 |
| 已选中 Frame 后单击某个图像框 | 选中该图像框，显示边框和控制点 |
| 拖已选中图像框 | 调整图像框的页内位置 |
| 双击已选中图像框内的照片 / 点击“裁切” | 进入照片内容编辑，固定图像框 |
| 在 Fill 照片上按住右键拖动 | 即时调整裁切焦点，松开后保存一次；不打开右键菜单 |
| 点击画布空白 | 完成已提交编辑并清除选择；存在未提交裁切时先取消裁切 |
| Esc | 先取消当前手势或裁切，再退出图像框选择，最后清除 Frame 选择 |

首版每次编辑一个 Frame，不支持与卡片、Sequence 堆叠、Memo 混合多选。原有照片框选和全选范围保持；Frame 通过点击选择。

页面及图像框角点采用不同选中轮廓，只有当前层级显示手柄。页内事件不冒泡触发 Table 照片预览、框选或页面移动。

### F04：页面和图像框调整

- Frame 可在 Table 中移动、置顶；选中后右侧以 Frame 设定栏取代 Photo Sources，显示页面规格、模板与编辑控件。选中图像框时，Frame 设置仍留在上方，下方展开该框的几何、圆角、照片显示、裁切、置顶和删除选项。
- Frame 角点等比改变显示比例，建议范围 0.1–4 个世界单位/pt；物理尺寸、内部排版坐标和裁切参数不变。
- 页面规格变化默认保留图像框物理尺寸与位置；超出页面的部分按页面边界裁切，并提示用户。此操作不自动应用模板，可一键重新应用当前模板。
- 单个图像框可拖动及八点缩放，也可输入 X/Y/W/H；界面单位为 mm，最小宽高 1mm，Shift 缩放保持比例。
- 图像框需至少与页面相交 1mm×1mm；可超出页面但不能完全移失，页面外不显示照片。
- 拖动图像框接近页面或其他图像框的边缘、中心线时吸附，显示对齐虚线；需要精确位置时可输入数值。
- 右侧醒目的“Add photo box”可随时新增图像框；选中图像框可通过按钮或 Delete/Backspace 单独删除，不依赖模板容量。图像框可置于其他图像框之前。
- 调整框尺寸保留照片模式、缩放倍数和焦点，再按新框范围约束照片位置。

### F05：Fit / Fill 与裁切

- Fit：完整显示照片，允许框内留白。Fill：填满图像框，保持照片比例并裁切多余部分。
- 照片缩放 100%–800%，以所选 Fit/Fill 的基础比例为 100%；拖照片改变焦点，原文件不变。
- Fill 不得露白；Fit 中比图像框小的轴居中，比图像框大的轴允许平移。
- Fill 照片可直接右键拖动已裁切的内容；松开提交一次，Esc 或取消手势恢复原裁切。
- 照片首次放入图像框并加载完成后，以短暂的淡入和轻微缩放动画呈现；偏好减少动态效果时关闭动画。改变图像框层级不重新加载已显示照片。
- Enter /“完成”提交，Esc 取消本轮裁切，恢复进入裁切前的参数。
- 一次拖动、一次滑块手势或一次完整裁切确认只产生一步撤销。
- 裁切时，Table 视口缩放与平移应冻结至手势结束，避免两个坐标系统同时变化。

### F06：更换模板

1. 在右侧设定栏修改模板、方向、边距或间距，合法数值一经修改立即重排模板图像框，无需 Apply layout。
2. 沿用页面规格、名称和 Table 位置；模板管理的图像框按顺序更新几何，保留已有照片与裁切参数。
3. 手动新增的图像框保持原位。模板容量缩小时，原有已填照片的多余模板框转为手动框，避免丢失照片；空框可移除。
4. 每次有效修改均可撤销；界面预览与页面同步更新。

### F07：复制、删除和快捷键

- 复制 Frame：保留页面、排版和裁切，生成新的 Frame 与图像框 ID，在附近空位放置；照片仅共享 PhotoId。
- 删除 Frame：删除页面及其内部引用，保留素材和 Table 照片卡片；可撤销。
- Delete / Backspace 按选择层级执行：整页选择删除 Frame；图像框选择删除整个图像框；裁切中不删除对象。
- Ctrl/Cmd+C、V 在整页选择时复制粘贴 Frame；Ctrl/Cmd+Z 和重做使用 Table 的同一历史栈。
- 文本输入框获得焦点时按键作用于输入内容；名称编辑和中文输入法期间不触发画布删除或撤销。
- 清空照片保留图像框；“Remove photo box”删除整个图像框及其照片引用，但不删除原照片。

### F08：保存、恢复与外部变化

| 情况 | 行为 |
|---|---|
| 完成创建、编辑、复制或删除 | 经现有 Table 保存流程持久化 |
| 拖动中 | 仅显示临时预览，结束后保存一次；取消不保存 |
| 刷新或重开项目 | 恢复 Frame、页面规格、图像框、照片和裁切；选择状态可不恢复 |
| 本地保存失败 | 保留编辑状态，使用现有重试及恢复备份入口 |
| 云同步失败 | 沿用现有本地已保存/待同步状态，不把云失败显示成本地已丢失 |
| 删除 Table 卡片、移出 Group 或 Sequence 变化 | Frame 中的照片引用不变 |
| 原片目录离线或失去授权 | 保留框和裁切，显示缺图占位及现有重新连接入口 |
| 复制项目或备份恢复 | Frame、图像框及 PhotoId 按项目复制规则重新映射 |
| Sequence Named Version / Compare | 保持 Sequence 内容范围，不把 Frame 纳入序列版本 |

Frame 名称及图像框虚线是编辑辅助，不属于纸面内容。缺图时仍能调整排版，不自动清空引用。

| A22 | 选择 Frame / 图像框 | 右侧保留 Frame 设置；选中图像框时，照片相关设置在其下方展开 |
| A23 | 黑白背景、图像框圆角与出血辅助线 | 页面显示即时更新，每个图像框圆角独立，刷新后恢复；无 Export DPI 或 Caption 控件 |
| A24 | 图像框置顶和键盘删除 | 重叠框可置顶；选中框按 Delete/Backspace 删除图像框，原素材保留 |
| A25 | 放入照片与图像框置顶 | 照片加载后播放进入动画；置顶时已经显示的照片保持可见，不闪回 Loading |
| A26 | Frame 与 Table 照片重叠 | 默认照片在页面上方，包括旧项目中的 Frame；选中 Frame 不遮盖照片，主动 Front 后页面可显示在照片之上 |

性能目标在既有 Table 大工作区基线上验证：增加 50 个、每个 4 张照片的 Frame，仅加载可见页面的图片；持续拖动不触发逐帧数据库写入；离开画布后预览 lease 被释放。记录设备及实际耗时，不在未测量前承诺固定帧率。

## 8. 交付分段

1. **可保存的页面骨架**：六种模板生成、创建、显示、移动、复制、删除、撤销、数据迁移。
2. **照片试排闭环**：填图、替换、清空、换位、Fit/Fill、裁切、图像框调整、页面属性。
3. **集成验收**：更换模板、跨对象手势、保存失败恢复、备份/云同步、离线照片和性能回归。

首版完成标准为上述三段共同通过，不以“页面能显示”代替完整交互与保存闭环。
