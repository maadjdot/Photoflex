## 1. 交付原则

一个分支持续承载本次文档修订及后续 Layout 开发。每个阶段产出可运行、可验证的纵向切片；完成所有阶段且满足第 4 节门槛，才称 Layout 首版完成。阶段编号用于安排依赖，不要求新增一套发布或插件机制。

七项核心能力均在首版内：页面尺寸与单双页查看、图像框、照片缩放裁切、文字、五种可调模板、阅读、固定尺寸 PDF。首版收窄的是高级变体：已有文档改尺寸、多选变换、复杂吸附、自动填图、PDF 对页合并/范围/质量档位及网页输出。

## 3. 关键实施顺序

1. **先让数据可保留。** 在任何正式 Layout 入口开放前完成存储、备份、云同步和关联删除。新文档建立与唯一性检查放在同一存储事务；路由导航只发生在创建成功之后。
2. **再让一页可编辑。** 先以真实 Sequence 照片做单页的图像框、裁切、文字、保存与恢复，随后补页面管理和对页查看。模板调用共享几何规则，一次应用产生普通框，不把 Table Frame 的即时重排状态复制进 Layout。
3. **保持排版单一来源。** 页面尺寸、图像裁切和文字行结果在编辑、阅读、PDF 之间共享。预览可以降采样，但不能另写一套裁切和换行公式。
4. **最后打开正式导出。** PDF 正式功能在中文可复制/搜索、缺图预检、取消不下载部分文件通过后才开放。现有 Sequence PDF 不作为替代完成项。

## 4. 验收与证据

| 检查 | 最小证据 |
|---|---|
| 数据与迁移 | 新旧项目、一个 Sequence 一个 Layout、修订冲突、备份导入、项目复制、云端往返、删除 Sequence/Project 的自动化测试 |
| 页面与图像 | 页面排序/对页顺序、五模板、Fit/Fill、焦点约束、框手势取消与一次撤销的模块测试；真实浏览器拖放测试 |
| 文字 | 简体中文输入法、显式换行、缺字与溢出定位；编辑、阅读和 PDF 使用同一排版结果的样本比较 |
| PDF | 物理尺寸、页数页序、空白页、照片裁切、字体嵌入；目标 PDF 阅读器中手工或自动核对中文显示、复制、搜索；取消/失败不产生下载 |
| 恢复与性能 | 保存失败保留草稿；刷新/返回/账号切换不丢“已保存”内容；50 页、500 照片实测内存和响应，200 页与单页 50 对象记录观察数据 |

执行项目现有 `pnpm test`、`pnpm typecheck`、`pnpm build` 与相关 Playwright 场景。测试关注接口行为和真实跨模块流程；不为每个小型 UI 包装或只读样式写镜像测试。性能数据记录设备、文档规模、测量路径和结果；在测量前不宣称 200 页性能已达标。

## 5. 暂缓与下一阶段

首版后先根据使用反馈评估互动网页作品集：从同一 Layout 快照导出可离线打开的网页包，提供章节导航、翻页和照片放大，并单独验证手机布局、素材体积与文字安全。接着可评估 Sequence 节奏检查。复杂文字、跨页对象、自定义模板、印刷标准和网页托管分别立需求，不预先增加空的扩展接口。
