## 已交付

- 可新建、拖动、八向缩放、复制和删除纯文本框。新建后焦点进入页面内文字框；已有框双击编辑。右栏保留字号、颜色、行距和左/中/右对齐，框的位置与尺寸在页面上直接调整。文本框缩放不改变字号。
- 中文输入法组合输入期间只更新框内输入草稿，组合结束后提交；普通输入按连续文字动作合并撤销历史。文字经现有 Layout 保存链写入，刷新后恢复。粘贴进入原生 `textarea`，只保留纯文本。
- `layoutText` 按物理页点数计算显式换行、自动换行和行距。结束框内输入后，编辑页面与阅读视图共用该结果及 `LayoutTextView`。页面和右栏不显示缺字、溢出提示。
- 使用 Noto Sans CJK SC Regular 2.004，来自 [官方 Sans2.004 版本](https://github.com/googlefonts/noto-cjk/releases/tag/Sans2.004)，随项目包含 [SIL OFL 1.1 许可证](../src/assets/fonts/NotoSansCJKsc-LICENSE.txt)。字体文件 SHA-256：`2C76254F6FC379FDDFCE0A7E84FB5385BB135D3E399294F6EEB6680D0365B74B`。
- 阅读视图隐藏编辑侧栏、照片条、框线、手柄和操作工具；沿用相同页面、裁切和文字呈现，提供前后翻页、页码、单双页查看和缩放。退出恢复进入前的页码、单双页设置及缩放；阅读不写入文档历史。
